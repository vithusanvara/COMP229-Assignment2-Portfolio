# Vithusan Varatharajan | React Portfolio

A personal portfolio website built with React and Vite for COMP 229
at Centennial College.

The portfolio introduces my background, highlights my projects and
technical skills, and provides access to my résumé.

## Features

- Responsive layout for desktop and mobile devices
- Personal introduction and About section
- Project showcase
- Technical skills and services
- Contact section
- Clickable profile photo
- Résumé PDF that opens in a new tab

## Technologies

- React
- Vite
- JavaScript
- HTML
- CSS

## Getting Started

### Prerequisites

Install Node.js and npm.

### Run Locally

1. Clone this repository.
2. Open a terminal in the project folder.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in the terminal.

## Production Build

Generate a production build:

    npm run build

Preview the production build:

    npm run preview

## Project Structure

    src/
      assets/       Images and résumé PDF
      App.jsx       Portfolio components and content
      App.css       Portfolio styling
      main.jsx      React entry point
    public/         Public assets
    index.html      HTML entry point
    package.json    Dependencies and scripts
